# Структура сайта перед дизайнерской модернизацией

Согласовано 9 октября 2026 года: ровно 10 публичных HTML-страниц, включая юридические документы.

| Адрес | Назначение |
|---|---|
| `/` | Главная, задачи, объекты, пять направлений, проблемомер, заявка |
| `/services/distancionnaya-otsenka/` | Дистанционная инженерная оценка |
| `/services/akusticheskiy-zamer/` | Акустический замер и обследование |
| `/services/proektirovanie/` | Инженерное акустическое проектирование |
| `/services/spetsproekty/` | Разработка специальных проектов — самостоятельное ключевое направление |
| `/services/promyshlennaya-akustika/` | Промышленное акустическое проектирование |
| `/about/` | О ЦИА, контакты и география |
| `/blog/` | Все десять статей целиком, оглавление, раскрывающиеся блоки |
| `/privacy.html` | Политика обработки персональных данных |
| `/consent.html` | Согласие на обработку персональных данных |

Отдельных каталогов услуг и объектов, страниц городов, отдельных статей и QR-страницы больше нет. Проблемомер расположен на главной. Статьи доступны по якорям `/blog/#slug`; якорь автоматически раскрывает выбранную статью. Источники снятых страниц сохранены в `content/objects/` и `content/geography/` для редакционной работы, но сборщик их не публикует.

На GitHub Pages нет серверного механизма индивидуальных 301-перенаправлений. Старые адреса снятых страниц возвращают 404; внутренние ссылки обновлены. При переезде на хостинг настроить перенаправления: города → `/about/#geography`, статьи → `/blog/#slug`, объекты → соответствующий блок главной, каталог услуг → `/#services`, QR → `/#diagnose`.

Текущий этап меняет архитектуру сайта. Финальное визуальное оформление, сокращение повторов в текстах и UX всех блоков — следующий этап работы с дизайнером. Настройки отправки формы, аналитики и юридические реквизиты не менялись.
